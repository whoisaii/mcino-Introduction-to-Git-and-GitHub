# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

1. Open an issue describing the proposed change or bug.
2. Fork this repository and create a descriptive branch.
3. Make a focused change, preserving the calculator’s documented behaviour.
4. Test valid whole-number inputs, decimal inputs, zero inputs and invalid inputs.
5. Submit a pull request with a summary and the checks performed.

Please follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Do not include passwords, tokens or personal information in issues or pull requests. Contributions are made under the repository’s Apache License 2.0.
